Tested programs

Every complete Raku program in these books is compiled and run at build time under two compilers — Rakudo (the reference implementation) and Raku++ (the engine that runs code in your browser via Raku.js). A program gets a Run button only when it runs under Rakudo and Raku++ reproduces the same output. Of 1341 Raku programs across the books: 349 run in the browser, 908 are illustrative fragments (no Run button), 29 need a local environment (files or the command line), 28 use concurrency the single-threaded in-browser engine can’t run, and 27 are valid programs the in-browser engine cannot run correctly yet.
